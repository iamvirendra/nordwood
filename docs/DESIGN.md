# NordWood visual system

The site uses a cream-led palette: soft cream `#F4F0E6`, charcoal `#2C302E`, warm champagne `#E8D8B6`, and near-black `#111111`. Cream leads the navigation, page introductions, product areas, and craft study. Charcoal provides structure in buttons, the footer, and the brief woodworking intro. Champagne is reserved for quiet accents, surfaces, and details against dark imagery. Natural wood photography and illustrations retain their material colours.

Edit shared colour tokens in `src/styles/global.css`. Pale champagne is too light for small text on cream, so `--accent-ink` provides a readable bronze tone for those details. `--muted` is for light surfaces and `--muted-dark` for charcoal.

Use `public/images/nordwood-logo.png` as the main NordWood logo on brand surfaces. It is the original supplied transparent PNG; preserve its proportions and natural wood colours. `src/data/brand.js` holds the shared image metadata. The logo remains visible in the header on mobile, and is also used in the homepage brand slide, browser favicon, touch icon, and decorative contact-team avatars. Pair it with the supplied `public/images/nordwood-wordmark-hd.png` wherever the brand name is presented as a standalone wordmark. `BrandWordmark` displays the original green artwork through a CSS window around its lettering, avoiding excess transparent spacing without altering the PNG. The shared footer uses the supplied combined logo from `1000689550.png`, stored unchanged as `public/images/nordwood-footer-logo.png` (4096 × 4096). Its CSS window removes excess transparent margins while preserving the complete wood-disc and wordmark artwork, displayed on a light panel for contrast. Preserve ordinary brand mentions in prose, copyright, metadata, accessibility labels and prepared messages as text.

Motion is implemented with CSS, SVG, IntersectionObserver, and the browser animation API, without an animation dependency. `src/motion` owns route entrances, scroll reveals, gallery/interaction motion, and the saved preference. Mark new sections with `data-motion="rise"` or `data-motion="image"`; use `data-page-enter` on stable page-introduction elements.

The homepage craft section uses the supplied exploded-view construction study. `DoorAssembly` animates individual photographic parts from the unchanged reference image using SVG clipping and transforms. Visitors can switch between assembled and exploded views or scrub the separation with a native range control; there is no autoplay or video. Reduced motion removes transitions while preserving every view. The assembly uses the full section width, with the desktop layout sized to one viewport below the sticky header. Single-door product pages include a compact construction reference card. These illustrations are kept separate from catalog photographs and confirmed product specifications. See `docs/CRAFT_REFERENCES.md` for mapping and provenance.
